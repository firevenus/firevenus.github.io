让它真正省掉点击

  1. 设为浏览器启动页：Chrome / Edge 设置 →「启动时」→ 打开特定网页 → 添加本页地址。开机即见，5 个站点就在眼前。
  2. 允许本站弹窗：首次点「一键打开」若只开出一个标签，地址栏右侧点「弹窗已拦截」→ 始终允许本站，之后一次全开。
  3. 固定到书签栏：把本页拖到书签栏，或按 ⌘/Ctrl + D。

说明：Gmail / X / LinkedIn / YouTube 都在响应头里禁止被 iframe 嵌入（X-Frame-Options），且登录态绑定各自域名，因此无法在本站内「内嵌预览」——这正是做成本页导航而不是嵌入网页的原因。

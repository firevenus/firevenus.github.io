# firevenus.github.io

个人博客 - 游戏开发、技术笔记与产业观察

## 技术栈

- [VitePress](https://vitepress.dev/) - 静态站点生成器
- GitHub Pages - 免费托管
- GitHub Actions - 自动构建部署

## 本地开发

```bash
npm install
npm run docs:dev
```

## 构建部署

```bash
npm run docs:build
```

推送到 main 分支后，GitHub Actions 自动构建并部署到 GitHub Pages。
